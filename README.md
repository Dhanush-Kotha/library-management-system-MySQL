# Library Management System — MySQL

A relational Library Management System built using MySQL to manage members, books, suppliers, book issues, returns, and fines. This project demonstrates practical SQL concepts including database design, primary and foreign keys, JOINs, subqueries, filtering, aggregation, and GROUP BY operations.

## Tech Stack

* MySQL
* SQL
* MySQL Workbench

## Key Features

* Member and book management
* Supplier and fine details
* Book issue and return tracking
* Relational database design
* SQL queries and data analysis

## Future Scope

Can be extended with a Python backend, web interface, REST API, authentication, automated fine calculation, and an admin dashboard.
